# Interface decision

User delegated approach, stack and design selection. This session uses direct code implementation to match the lean-prototype request; no standing workflow preference is stored.

Grounded directions considered: merchant ledger, invoice sheet, port waybill, conversation inbox, exchange quote board, bilateral signing room, importer's correspondence desk. The assigned seventh direction (seed c9cc1929) joins correspondence and a cost sheet on one surface. Its medium is a daylight working desk, not a simulated physical illustration.

The gravity garden loses task clarity and audience identification; retain its discipline of making input changes visibly affect an outcome. The sneaker archive loses both; retain consistent row labeling. The botanical folio is competitive on comparison clarity but loses scene relevance; retain fixed alignment between quote options. The developer console is competitive on density but loses familiarity for nontechnical traders; retain persistent panes and isolated reset. The one-bit desktop loses both; retain unambiguous selected states. The oscilloscope loses both; retain a precisely labeled scenario control.

Interface: forest navigation, warm white working surfaces, clear numeric hierarchy, restrained apricot uncertainty, real focus and hover states. No decorative imagery. First screen owns the full decision, while sealing and verification are later states of the same workflow.
