# SANAD app surface

## Scope and mode

Operate mode across the React/Vite web app and Expo mobile app. Chat and Finance remain separate at every width; all current workflows, facts, labels, calculations, dialogs, and states remain in scope.

## Audience, job, and action

Small importers reviewing one supplier invoice from a live conversation. The user must compare full buyer outlay with possible supplier receipt, assign downstream fees, and create/sign/verify one shared record without decorative ambiguity.

## Chosen direction

Mashrabiya Daylight Ledger owns the world: porcelain surfaces, cropped diffused geometric daylight, ink-dark figures, and restrained lilac/mint/pink state color. Parametric Arabic Counterseal supplies state and motion: open for unresolved, aligned for agreed, closed for sealed. Approved comp: `.impeccable/mocks/hybrid-a.webp`.

Memorable moment: the €6,000 invoice is the luminous hinge inside Chat; its single bridge opens Finance, where the same counterseal resolves through Compare, Agree, and Sign.

## Comp translation

The generated “strong payment track record” claim is rejected and replaced with the existing neutral SANAD insight. Generated message wording is not authoritative; current product copy and arithmetic remain source truth. The comp’s extra menu icon is omitted because navigation remains Chat/Finance only.

## Constraints and unresolved decisions

No flow changes, no invented financial claims, no real provider claims, no ornamental geometry behind dense text, and no rasterized core UI. Desktop keeps a rail and one centered work surface. No unresolved product decision remains.
